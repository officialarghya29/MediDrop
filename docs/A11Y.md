# Accessibility register

Last updated: 2026-11-20

Status: **NOT AUDITED. No axe, Lighthouse, keyboard or screen-reader gate has been run.**

This register records what exists in the code, what is missing and what must be proven before
the v5 WCAG AA claim. Static presence of an ARIA attribute is not a pass.

## 1. v5 requirements

- WCAG AA.
- Keyboard navigation.
- Touch targets at least 44px.
- Loading, empty, error and success states on every screen.
- axe zero serious/critical findings.
- Screenshots at 390px and 1440px.
- Light and Ops Night modes for pharmacy, delivery and admin.
- English, Hindi and Bengali UI.
- Honor `prefers-reduced-motion`.

## 3. WCAG AA working checklist

| Criterion area | Current position |
| --- | --- |
| 1.1 Text alternatives | Some icons are `aria-hidden`; no full image/icon audit. |
| 1.3 Adaptable structure | Semantic headings and landmarks exist in places; no full structure audit. |
| 1.4 Distinguishable | Contrast and zoom were not measured. |
| 2.1 Keyboard accessible | No keyboard-only pass; modal focus management is incomplete. |
| 2.4 Navigable | Focus style and labels exist; no skip link; no full focus-order audit. |
| 2.5 Input modalities | Touch-target size and pointer alternatives were not measured. |
| 3.3 Input assistance | Field errors and validation messages exist in shared components; coverage is unverified. |
| 4.1 Compatible | Some ARIA roles/labels exist; no automated or manual conformance pass. |

## 4. Required gate for M14

1. Add axe to component/E2E tests and fail CI on serious or critical findings.
2. Run Lighthouse on the customer home, search, checkout, tracking and admin screens.
3. Record a keyboard-only pass and a screen-reader pass.
4. Measure contrast and touch targets; fix failures rather than suppressing rules.
5. Add a skip link and complete modal focus trap/restore behaviour.
6. Add 390px and 1440px screenshots in light and Ops Night modes.
7. Add i18n and a PWA manifest/service worker, then re-run the gate.
8. Publish the exact tool versions and reports beside the result.
