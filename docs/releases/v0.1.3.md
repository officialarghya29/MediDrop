# MediDrop 0.1.3 — substitute reliability

**Status: foundation release. Pre-pilot; not `1.0.0`.**

This patch makes the lower-cost substitute comparison reliable when the caller does not select a
pharmacy.

## Fixed

- The API now walks price-ordered stock and selects the cheapest pharmacy that is approved, active and
  accepting orders. A paused cheapest pharmacy no longer hides a valid alternative.
- Added a regression covering the unavailable-cheapest-pharmacy case.

## Verification

- Backend: 40 passed, 0 failed.
- Frontend: 13 passed, 0 failed.
- Production frontend build: passed.
- GitHub CI on the tagged commit: all three jobs successful.
- Live PostgreSQL fallback check: the cheapest Salt Lake pharmacy was paused; the API selected
  Bhowanipore and returned the ₹255 value pack against ₹343 (₹88, 26%). Demo prices only.

This is published as a normal GitHub release so it appears in the repository sidebar. It remains a
