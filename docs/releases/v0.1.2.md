# MediDrop 0.1.2 — lower-cost substitutes

**Status: pre-release. Not pilot-ready and not `1.0.0`.**

This release adds a safe lower-cost substitute comparison to the medicine detail page.

## Added

- `GET /api/v1/medicines/{id}/substitutes` with an optional selected pharmacy and result limit.
- Comparison only against products with the same generic composition, strength, dosage form, pack size,
  prescription flag and schedule class.
- Only in-stock candidates that are strictly cheaper at the selected pharmacy.
- Price, savings amount, savings percentage and stock count in the response and UI.
- Prescription candidates carry a mandatory pharmacist-review notice and are never applied automatically.
