# MediDrop 0.1.1 — foundation hardening

**Status: pre-release. Not pilot-ready and not `1.0.0`.**

This release makes the current foundation build publicly downloadable while keeping the launch
gates explicit. It contains the M1 safety slice and the deep-scan fixes.

## Highlights

- Tenant-scoped pharmacy invoices and prescription review history.
- Refund terminal states require the refund ledger; no direct `DELIVERED → REFUNDED` bypass.
- Verified pharmacist identity and controlled-medicine schedule enforcement.
- OTP handover only during active delivery; no OTP/reset bodies in console logs.
- Public pharmacy/delivery onboarding fixed; no password echo or duplicate-phone accounts.
- PDF/JPEG/PNG magic-byte checks for prescription and pharmacy documents.
- Delivery failure has the correct actor/state; admin settings and refund IDs are hardened.
- Runtime build metadata and aligned `0.1.1` versions across API, web and CI.

## Verification

- Backend: 37 passed, 0 failed.
- Frontend: 13 passed, 0 failed.
- Production frontend build: passed.
- CI on the release commit: backend, frontend and PostgreSQL smoke all successful.

## Launch blockers

This is deliberately a pre-release. The separate pharmacist role, pilot gates, provider
certification, 50-way/250K/accessibility/browser gates, M2–M15 engines and legal/ops sign-off are
still open. See `docs/VERSIONS.md`, `docs/AUDIT.md` and `docs/PROGRESS.md`.
